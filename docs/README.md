# Documentation

Welcome in. This folder is everything that didn't fit on the front door, sorted by the kind of question you're asking. If you're brand new, start with getting started and concepts, in that order. If you already know your way around and just need a fact, jump straight to the reference.

| Folder | What lives there |
| --- | --- |
| [getting-started/](getting-started/README.md) | The fastest honest path from a fresh checkout to something working |
| [guides/](guides/README.md) | Step-by-step help for real tasks: seeding, operating, troubleshooting, releasing |
| [concepts/](concepts/README.md) | Plain explanations of what this collector is, why it exists, and where its edges are |
| [reference/](reference/README.md) | The exact tables: [configuration](reference/configuration.md) and [fact kinds](reference/facts.md) |
| [architecture/](architecture/README.md) | Where this sits inside Eshu, what it's made of, and the versions it pins |
| [diagrams/](diagrams/README.md) | Every picture in one place, each with a plain-words version underneath |
| [decisions/](decisions/README.md) | Decision records, plus the template for adding new ones |
| [contributing/](contributing/README.md) | How to set up, check your work, and land a change |

The [README](../README.md) back at the root stays short on purpose. Think of it as the front door and this folder as the rest of the house.
